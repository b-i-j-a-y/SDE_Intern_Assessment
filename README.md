# Project Overview

This repository contains my implementation of the Xapien Innovatus (XIPL) Software Engineering Intern Technical Assessment.

The project covers:

- Q1: Garment and body understanding using Florence-2
- Q2: Human parsing and garment segmentation using Grounding DINO, SAM and human parsing
- Q3: Open-source virtual try-on inference and generated try-on outputs
- Q4: Automated try-on quality evaluation
- Q5: Streamlit-based try-on demonstration with image-content guardrails
