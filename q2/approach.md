# Approach

## Objective

The objective of this task is to generate all preprocessing information required by a virtual try-on system.

Instead of relying on a single model, a modular pipeline was designed using specialized open-source models.

---

# Model Selection

## Grounding DINO

Grounding DINO was selected because it is an open-vocabulary object detector.

Advantages:

- Detects persons without custom training
- Detects garments using text prompts
- High localization accuracy

---

## Segment Anything Model (SAM)

Grounding DINO provides only bounding boxes.

SAM was used to convert those bounding boxes into accurate pixel-level segmentation masks.

Advantages:

- Accurate masks
- Works with any object
- Zero-shot segmentation

---

## SegFormer Human Parsing

Human parsing requires semantic understanding of body parts.

SegFormer was selected because it produces pixel-wise labels for:

- Hair
- Face
- Arms
- Upper Clothes
- Pants
- Shoes
- Belt
- Background

This information is required for agnostic image generation.

---

# Pipeline Design

The pipeline consists of four independent modules.

1. Person Detection
2. Person Segmentation
3. Human Parsing
4. Garment Segmentation

Each module can be executed independently.

---

# Agnostic Image Generation

The agnostic image is generated by removing the clothing regions identified by the human parsing model.

The following labels are removed:

- Upper Clothes
- Dress
- Belt

This image is later used as input for the virtual try-on model.

---

# Edge Case Evaluation

The pipeline was evaluated on multiple challenging cases.

Examples include:

- Side pose
- Crossed arms
- Seated person
- Images without a person

This evaluation helps identify the strengths and limitations of the pipeline.

---

# Limitations

Observed limitations include:

- Grounding DINO may produce false positives in images without a person.
- Human parsing accuracy decreases under severe occlusion.
- SAM performance depends on the quality of the detected bounding box.

---

# Future Improvements

Possible future improvements include:

- Fine-tuning Grounding DINO for clothing detection.
- Using SAM2 for improved segmentation quality.
- Incorporating pose estimation for more robust agnostic image generation.
- Optimizing inference speed for real-time applications.
